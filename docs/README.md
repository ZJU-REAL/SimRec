# Documentation

The public README is the entry point. This directory records the operational
protocols needed to reproduce a run without exposing local paths, credentials,
data, checkpoints, or private evaluation records.

- [Training](TRAINING.md) explains data splits, portable configuration, and the
  training launcher.
- [Evaluation](EVALUATION.md) defines held-out evaluation and reported metrics.
- [Data construction](../data/README.md) links the source datasets and records
  the local preprocessing protocol.

The paper is authoritative for claims, experimental results, and prompt text.
When it becomes public, add its citation and stable PDF link here.
